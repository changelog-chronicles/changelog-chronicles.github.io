dagster

dagster-io/dagster · PyPI dagster · JSON · edit

  1. 2026-11-12 1.13.30 breaking

    Breaking: Python 3.10 is no longer supported; Dagster now requires Python 3.11 or later, so upgrade your Python environment first.

    Copy the latest asset materializations from one deployment to another while keeping their original timestamps.

  2. 2026-11-05 1.13.29 feature

    Use mobile layouts on the code location overview, code locations list, and sensor and schedule detail pages.

  3. 2026-10-30 1.13.28 breaking

    Breaking: dagster-snowflake now requires snowflake-snowpark-python 1.37.0 or newer and snowflake-connector-python 3.14.0 or newer; upgrade those packages.

    Run an existing Databricks job by ID through Dagster Pipes using the new preview run_job method on the Databricks clients.

  4. 2026-10-26 1.13.27 breaking

    Breaking: New Dagster+ organizations no longer get the Credit Limit Exceeded alert policy by default; create it manually if you rely on it.

    Use a mobile layout on the run details page showing the run's tags, logs, and steps.

  5. 2026-10-09 1.13.26 breaking

    Breaking: dagster-dbt no longer installs dbt-core; install the dagster-dbt[dbt-core] extra instead, and never alongside dbt Fusion's dbt package.

    Target a different deployment with the new deployment option in dg list envs, dg plus create env, and dg plus pull env.

  6. 2024-10-10 1.8.11 breaking poem

    Breaking: AutomationCondition.eager() now only launches runs for partitions that become missing after the condition is added, so historical missing partitions are no longer backfilled automatically.

    Create GitHub pull requests and branches directly from the GithubClient with the new create_pull_request and create_ref methods.

  7. 2024-10-03 1.8.10 breaking

    Breaking: The new navigation is now on for all users; if you rely on the legacy navigation, turn it back on via the feature flag.

    Attach run-level tags separately from job definition tags by passing the new run_tags parameter to jobs.

  8. 2024-09-26 1.8.9 feature

    Set a deployment-wide maximum runtime in run monitoring so any run exceeding max_runtime_seconds is terminated.

  9. 2024-09-20 1.8.8 feature

    Materialize a range of partitions from the command line using the new partition-range option on the asset materialize command.

  10. 2024-09-12 1.8.7 breaking

    Breaking: DbtCliResource's project_dir argument now overrides the DBT_PROJECT_DIR environment variable; remove or align the variable if you relied on it winning.

    Wipe specific asset partitions directly from the execution context in user code using DagsterInstance.wipe_asset_partitions.
