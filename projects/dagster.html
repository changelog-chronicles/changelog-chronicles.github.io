dagster

dagster-io/dagster · PyPI dagster · JSON

  1. 2026-11-12 1.13.30 breaking

    Breaking: Python 3.10 is no longer supported, so Dagster now requires Python 3.11 or later; upgrade your Python version before upgrading Dagster.

    Copy the latest asset materializations from one deployment to another, keeping original timestamps, with the new dagster-cloud deployment copy-materializations command.

  2. 2026-11-05 1.13.29 feature

    View the code location overview, deployment code locations list, and sensor and schedule detail pages in new mobile layouts, with faster run log loading and search.

  3. 2026-10-30 1.13.28 feature

    Breaking: dagster-snowflake now requires snowflake-snowpark-python 1.37.0 or newer and snowflake-connector-python 3.14.0 or newer, so upgrade those packages if you pin older versions.

    Trigger an existing Databricks job by ID through Dagster Pipes using the new preview run_job() method on PipesDatabricksClient and PipesDatabricksServerlessClient.

  4. 2026-10-26 1.13.27 feature

    Use a mobile layout on the run details page that shows the run's tags, logs, and steps.

  5. 2026-10-09 1.13.26 breaking

    Breaking: dagster-dbt no longer installs dbt-core automatically; install it with the dagster-dbt[dbt-core] extra, and never alongside dbt Fusion's dbt package.

    Target a specific deployment with the new deployment option on dg list envs, dg plus create env, and dg plus pull env commands.

  6. 2024-10-10 1.8.11 breaking poem

    Breaking: Experimental AutomationCondition.eager() now only launches runs for partitions that become missing after the condition is added, so existing missing historical partitions are no longer backfilled automatically.

    Create GitHub pull requests and branches from GithubClient, and give an asset multiple kinds with the experimental kinds parameter.

  7. 2024-10-03 1.8.10 feature

    Set run_tags on jobs so they attach only to runs, separating run-level tags from definition-level tags on jobs.

  8. 2024-09-26 1.8.9 feature

    Set a max_runtime_seconds option in run monitoring so any run exceeding that runtime is terminated, without tagging each job individually.

  9. 2024-09-20 1.8.8 feature

    Run dagster asset materialize with a partition range option for single-run backfill assets, and use the new on_missing automation condition to materialize partitions once all parents are filled.

  10. 2024-09-12 1.8.7 feature

    Breaking: AssetSpec now raises an error at construction for invalid group names, and DbtCliResource project_dir now overrides DBT_PROJECT_DIR; fix group names and check your environment.

    Attach relation identifier metadata automatically to assets stored with a DbIOManager, and get rows_loaded metadata on dlt assets.

Briefs and poems are written by Claude from the release notes; the release notes are the source of truth. Data for agents: llms.txt.
