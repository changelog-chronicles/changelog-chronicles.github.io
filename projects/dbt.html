dbt

dbt-labs/dbt · PyPI dbt-core · JSON

  1. 2026-11-12 v1.12.7 feature

    Read the new state_decision_id attribute on RunResult, and opt into preferring adapter macro overrides for builtin macros with the builtin_macros_prefer_overrides behavior flag.

  2. 2026-11-11 v2.0.0-dev.44-test-pypi breaking

    Breaking: Existing local Unity attach options under config.lakecompute must move to config.duckdb; Lake Compute access is read-only, so Unity model writes are unsupported.

    Read AWS Databricks Unity Catalog tables from Lake Compute using Databricks profile PAT or OAuth M2M credentials, in read-only mode.

  3. 2026-11-06 v1.11.17 fix

    Nothing new for users.

  4. 2026-11-03 v2.0.11 breaking

    Breaking: Environment variables were renamed: DBT_AI_PROVIDER is now DBT_ENGINE_AI_PROVIDER, and the info-schema variables now use the DBT_ENGINE_ prefix; update any scripts or CI that set them.

    Configure BigQuery query reservations at the model and connection levels, and use the new state-mode flag in place of run-cache-mode.

  5. 2026-10-14 v2.0.8 feature

    Install the dbt and dbt-oss PyPI wheels on Python 3.10, since the minimum supported Python version was lowered to 3.10.
