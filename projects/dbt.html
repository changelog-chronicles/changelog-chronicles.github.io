dbt

dbt-labs/dbt · PyPI dbt-core · JSON · edit

  1. 2026-11-12 v1.12.7 feature

    Add a builtin_macros_prefer_overrides behavior flag so adapter overrides are preferred over base implementations for builtin macros.

  2. 2026-11-11 v2.0.0-dev.44-test-pypi breaking

    Breaking: Local Unity attach options under config.lakecompute no longer work; move them to config.duckdb.

    Read AWS Databricks Unity Catalog tables from Lake Compute using Databricks profile PAT or OAuth M2M credentials.

  3. 2026-11-06 v1.11.17 fix

    Nothing new for users.

  4. 2026-11-03 v2.0.11 breaking

    Breaking: Environment variables DBT_GENERATE_INFO_SCHEMA and DBT_INFO_SCHEMA_DIR are renamed with a DBT_ENGINE_ prefix, and DBT_AI_PROVIDER is now DBT_ENGINE_AI_PROVIDER; update your environment.

    Configure BigQuery query reservations at the model and connection levels.

  5. 2026-10-14 v2.0.8 feature

    Install the dbt and dbt-oss PyPI wheels on Python 3.10, since the minimum supported version was lowered.
