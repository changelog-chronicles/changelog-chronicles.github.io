dlt

dlt-hub/dlt · PyPI dlt · JSON · edit

  1. 2026-10-29 1.32.0 breaking

    Breaking: Naive scd2 timestamps are no longer treated as UTC, so a naive active_record_timestamp may stop matching active records; pass timezone-aware values.

    Load any Salesforce sObject, standard or custom, with the new salesforce_table source.

  2. 2026-10-07 1.31.0 breaking

    Breaking: Removed pendulum helpers like ensure_pendulum_datetime_utc from dlt.common.time and pendulum 3 is now required; switch to ensure_datetime_in_tz and upgrade pendulum.

    Load full snapshots with the new cdc merge strategy, which upserts rows and deletes destination rows missing from the snapshot.

  3. 2026-08-11 1.30.0 breaking

    Breaking: Failed load packages no longer auto-abort and raise LoadClientJobTerminalRetry instead of LoadClientJobFailed; set auto_abort_on_terminal_error to True to restore old behavior.

    Join datasets that live on different destinations in a single query using the dataset table join method.

  4. 2026-07-24 1.29.1 feature

    Declare runner instance requirements for jobs through require.instance, such as a size of medium.

  5. 2026-07-13 1.29.0 feature

    Replace ClickHouse tables atomically with the staging-optimized strategy, so a full replace never leaves the destination half-loaded.

  6. 2024-10-07 1.2.0 feature poem

    Merge data into SQLAlchemy destinations using the new merge write disposition support.

  7. 2024-09-26 1.1.0 feature

    Use a custom requests session with the REST API source to control how HTTP calls are made.

  8. 2024-09-16 1.0.0 breaking

    Breaking: The complex data type is deprecated and renamed to json, and foreign_key is dropped; update schemas and hints accordingly.

    Load data into any SQL database supported by SQLAlchemy using the new SQLAlchemy destination.

  9. 2024-08-28 0.5.4 feature

    Partition delta tables when loading data, using the newly added delta table partitioning support.

  10. 2024-08-13 0.5.3 breaking

    Breaking: DuckDB and MotherDuck parquet loads now match columns by name, so files relying on column order may load differently.

    Start load jobs continuously as loader slots free up, speeding up loading of packages with many files.
