dlt

dlt-hub/dlt · PyPI dlt · JSON

  1. 2026-10-29 1.32.0 breaking

    Breaking: Naive scd2 timestamps are no longer read as UTC, and drop_resources and pipeline.drop now drop all resource tables; check scd2 timestamps, and old jira and salesforce sources were rewritten.

    Use placeholders like load_id and boundary_timestamp in merge source_filter and destination_scope, so nested tables can prune destination partitions such as BigQuery ones when merging.

  2. 2026-10-07 1.31.0 breaking

    Breaking: Pendulum 3 or newer is now required and unofficial pendulum helpers in dlt.common.time are removed; also changed: filesystem timestamps, cursor types, JSON datetimes, Snowflake timestamps. Update code.

    Load full snapshots with the new cdc merge strategy, which upserts rows and deletes destination rows missing from the snapshot, across many destinations.

  3. 2026-08-11 1.30.0 breaking

    Breaking: Failed load packages no longer auto-abort and now retry, raising LoadClientJobTerminalRetry; filesystem layouts without ext now append extensions and table prefixes keep a trailing separator, changing file names.

    Join datasets that live on different destinations, such as DuckDB and S3 filesystem, in a single query through the dataset table join API.

  4. 2026-07-24 1.29.1 feature

    Declare runner instance requirements for jobs via require.instance, an open dictionary such as size medium, replacing the now-deprecated machine key.

  5. 2026-07-13 1.29.0 feature

    Use the staging-optimized replace strategy on ClickHouse for atomic table swaps, so a full replace never leaves the destination half-loaded.

  6. 2024-10-07 1.2.0 feature poem

    Use merge write disposition with the SQLAlchemy destination, and use incremental scd2 with a merge key.

  7. 2024-09-26 1.1.0 feature

    Use SQLAlchemy destinations with staging datasets, pass a custom session to the REST API source, and add DltResource objects to the REST API config.

  8. 2024-09-16 1.0.0 breaking

    Breaking: Major release: foreign_key hint is dropped in favor of nested references, the complex data type is deprecated for json, and terminal job errors now abort the load package; review the linked breaking changes list.

    Use the rest_api, sql_database and filesystem sources directly from dlt core, plus a new SQLAlchemy destination and SFTP support for the filesystem source.

  9. 2024-08-28 0.5.4 feature

    Use partitioning and schema evolution with merge on delta tables, and set custom valid-from and valid-to values for scd2 records.

  10. 2024-08-13 0.5.3 feature

    Load jobs now start continuously as loader slots free up, and a new get_delta_tables helper lets you optimize and vacuum Delta tables.
