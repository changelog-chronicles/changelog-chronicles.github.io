duckdb

duckdb/duckdb · PyPI duckdb · JSON

  1. 2026-10-21 v2.0.0 breaking

    Breaking: Integer division by zero now raises an error instead of returning NULL; the ICU extension was removed, DECIMAL now promotes past BIGINT, and the C++ API changed, so test queries and extensions.

    Query data with NEAREST BY joins, plus new variant functions, JSON set/insert/replace/remove, nested schemas, AFTER triggers, async Parquet and CSV I/O, and external resources.

  2. 2026-09-28 v1.5.6 fix

    Set the new enable_optimistic_write setting to control optimistic writes, backported from a later DuckDB version.

  3. 2026-07-22 v1.5.5 fix

    Use the duckdb:// URI scheme in the ADBC URI option, and query ADBC statistics through the new ADBC Statistics API support.

  4. 2026-06-17 v1.5.4 fix

    Set the experimental vacuum_rebuild_indexes option when attaching a database, and use new CLI dark-mode and light-mode options to control terminal background handling.

  5. 2026-06-17 v1.4.5 fix

    Nothing new for users.
