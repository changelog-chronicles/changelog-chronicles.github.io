duckdb

duckdb/duckdb · PyPI duckdb · JSON · edit

  1. 2026-10-21 v2.0.0 breaking

    Breaking: Integer division by zero now raises an error instead of returning NULL; guard divisors or handle the error in queries that relied on NULL.

    Run SQL against nested schemas, including creating, dropping, inserting into and querying tables within them.

  2. 2026-09-28 v1.5.6 breaking

    Breaking: Identifiers in error messages are now always quoted, so code or scripts matching error message text may need updating.

    Add an enable_optimistic_write setting to control optimistic writes.

  3. 2026-07-22 v1.5.5 feature

    Support the duckdb:// URI scheme in the ADBC driver's URI option.

  4. 2026-06-17 v1.5.4 feature

    Use the new experimental vacuum_rebuild_indexes option when attaching a database.

  5. 2026-06-17 v1.4.5 fix

    Nothing new for users.
