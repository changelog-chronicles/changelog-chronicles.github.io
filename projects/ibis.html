ibis

ibis-project/ibis · PyPI ibis-framework · JSON · edit

  1. 2026-02-07 12.0.0 breaking

    Breaking: Python 3.9 and PySpark versions below 3.5 are no longer supported; upgrade them, and check decimal types, since precision and scale are now inferred.

    Upsert rows into a table using the new upsert() method, which is built on MERGE INTO.

  2. 2025-10-15 11.0.0 breaking

    Breaking: Removed deprecated APIs such as ibis.case, String.to_date and Struct.destructure; switch to ibis.cases, as_date and Table.unpack.

    Read Databricks streaming tables directly through the Databricks backend.

  3. 2025-07-28 10.8.0 feature

    Build an Ibis schema directly from a SQLGlot definition using the new Schema.from_sqlglot method.

  4. 2025-07-27 10.7.0 breaking

    Breaking: Unpacking with overlapping column names now always overwrites existing fields; check code relying on the old behavior.

    Call to_sql() directly on any expression to get the SQL it compiles to.

  5. 2025-06-16 10.6.0 breaking

    Breaking: Polars sum now returns NULL where it previously did not, matching other backends; check code that relied on the old sum result.

    Create specific UUID values in expressions instead of only random ones.
