ibis

ibis-project/ibis · PyPI ibis-framework · JSON

  1. 2026-02-07 12.0.0 breaking

    Breaking: Python 3.9 and PySpark versions below 3.5 are no longer supported, and decimal precision and scale are now inferred, so upgrade Python and PySpark and check decimal types.

    Use upsert() to merge rows into tables via MERGE INTO, plus new SingleStoreDB and Materialize backends, PySpark 4.0 support, and pandas 3.0 compatibility.

  2. 2025-10-15 11.0.0

    No brief yet.

  3. 2025-07-28 10.8.0 feature

    Build an Ibis schema directly from a SQLGlot definition using the new Schema.from_sqlglot method.

  4. 2025-07-27 10.7.0 feature

    Breaking: Unpacking structs with overlapping column names now always overwrites the existing field; check code that relied on the previous behavior.

    Call to_sql directly on an expression to get its SQL, and compute kurtosis across supported backends.

  5. 2025-06-16 10.6.0 feature

    Set a BigQuery job ID prefix and per-query job config options on queries, and create specific UUID values in expressions.
