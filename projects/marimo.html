marimo

marimo-team/marimo · PyPI marimo · JSON

  1. 2026-10-19 0.25.2 breaking

    Breaking: Plots no longer auto-switch to a dark theme in dark notebooks for matplotlib, Plotly, Bokeh, and HoloViews; set the dark theme explicitly in your notebook if you want it.

    Download geographic dataframes and tables (GeoPandas, Arrow, DuckDB geometry) as GeoJSON or GeoParquet, and run notebooks on Python 3.15.

  2. 2026-10-01 0.25.1 feature

    Pass expand_outputs to ctx.edit_cell and ctx.create_cell, and use new marimo cache size and cache dir commands to inspect notebook caches.

  3. 2026-09-23 0.25.0 feature

    Run notebook sandboxes with Pixi to use Conda packages and native libraries, and save expanded cell outputs in the notebook file.

  4. 2026-09-11 0.24.2 feature

    See storage metadata for files at all times, rather than only in some cases.

  5. 2026-09-10 0.24.1 breaking

    Breaking: GitHub Models was replaced by GitHub Copilot, and cache config moved from experimental.cache to cache.store; switch to Copilot and update your cache settings.

    Export slide-layout notebooks as reveal.js decks to static HTML or interactive WebAssembly, and browse local folders and GitHub repositories in the Files panel.
