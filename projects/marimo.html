marimo-team/marimo · PyPI marimo · JSON · edit

  1. 2026-11-24 0.26.0 breaking

    Breaking: marimo 0.26 requires Python 3.11 or newer; upgrade Python from 3.10 before upgrading marimo.

    Send a failed cell's code and traceback to your connected coding agent from the editor footer.

  2. 2026-10-19 0.25.2 breaking

    Breaking: Plots no longer auto-switch to a dark theme in dark notebooks; set the dark theme explicitly in matplotlib, Plotly, Bokeh, or HoloViews.

    Download geographic tables and dataframes as GeoJSON or GeoParquet, alongside the existing CSV, JSON, and Parquet options.

  3. 2026-10-01 0.25.1 feature

    Pass expand_outputs to ctx.edit_cell and ctx.create_cell to control whether the created cell's outputs are expanded.

  4. 2026-09-23 0.25.0 feature

    Run notebook sandboxes with Pixi to combine Conda and PyPI packages in a notebook's inline configuration.

  5. 2026-09-11 0.24.2 feature

    See storage metadata for files every time, instead of only in some cases.

  6. 2026-09-10 0.24.1 breaking

    Breaking: Cache configuration moved from experimental.cache to cache.store, so update your marimo config; GitHub Models is replaced by GitHub Copilot.

    Export slide-layout notebooks as reveal.js decks in static HTML or interactive WebAssembly form.
