narwhals

narwhals-dev/narwhals · PyPI narwhals · JSON · edit

  1. 2026-11-17 v2.29.0 breaking poem

    Breaking: Built-in Dask support moved to the narwhals-dask plugin and is deprecated; install the plugin to keep using Dask.

    Use the new Map datatype, which supports a get operation for looking up values by key.

  2. 2026-10-27 v2.28.0 breaking

    Breaking: Results changed: rename now consistently raises DuplicateError, and var/std, mode, arg_min and arg_max return different values in some cases; update any code catching old errors.

    Use plugins for more IO and from_* functions, so third-party backends can read and build data frames.

  3. 2026-10-10 v2.27.1 fix

    Nothing new for users.

  4. 2026-10-05 v2.27.0 breaking

    Breaking: Floor division by zero on pandas-like backends now returns null, and str.slice with negative length or str.zfill with negative width now raises; check code relying on old results.

    Cast whole DataFrames or LazyFrames to new dtypes using the new cast method.

  5. 2026-09-08 v2.26.0 fix

    Nothing new for users.
