pillow

python-pillow/Pillow · PyPI pillow · JSON · edit

  1. 2026-10-16 13.0.0 breaking

    Breaking: Python 3.10 is no longer supported, so upgrade to Python 3.11 or newer; code using removed ExifTags.IFD.Makernote or _save_netpbm will fail.

    Resize images with the new Magic Kernel Sharp resampling modes.

  2. 2026-07-01 12.3.0 breaking

    Breaking: Non-image ImageCms modes were removed, so stop using them; also macOS retina screenshots are no longer resized by default.

    Open and save L mode AVIF images when Pillow is built with libavif 1.3.0 or newer.

  3. 2026-04-01 12.2.0 breaking

    Breaking: Encoding an empty image now raises ValueError instead of the previous error type, so update any code catching the old exception.

    Wrap text into lines that fit a given width using the new ImageText.Text.wrap() method.

  4. 2026-02-11 12.1.1 fix

    Nothing new for users.

  5. 2026-01-02 12.1.0 feature

    Pass a window ID to ImageGrab.grab() on macOS to capture a specific window.
