pillow

python-pillow/Pillow · PyPI pillow · JSON

  1. 2026-10-16 13.0.0 breaking

    Breaking: Python 3.10 is no longer supported, ExifTags.IFD.Makernote and GifImagePlugin._save_netpbm are removed, and XMP info is no longer a tuple; upgrade Python and adjust code using these.

    Resize images with the new Magic Kernel Sharp resampling modes, and pass a strip_namespaces argument to getxmp() to control XMP namespace handling.

  2. 2026-07-01 12.3.0 breaking

    Breaking: Non-image ImageCms modes were removed, ImageCms now errors on mode mismatches, and macOS retina screenshots are no longer resized by default; adjust code relying on these.

    Open and save L mode AVIF images with libavif 1.3.0 or newer, and use Pillow on Python 3.15 with new beta wheels.

  3. 2026-04-01 12.2.0 breaking

    Breaking: Encoding an empty image now raises ValueError instead of the previous error; update any code that catches the old exception type when saving empty images.

    Wrap text with the new ImageText.Text.wrap() method, and convert font files to usable fonts with FontFile.to_imagefont().

  4. 2026-02-11 12.1.1 fix

    Nothing new for users.

  5. 2026-01-02 12.1.0 feature

    Use the new get_flattened_data() method in place of getdata(), save APNG animations with float durations, and pass a window ID to ImageGrab.grab() on macOS.
