plotly

plotly/plotly.py · PyPI plotly · JSON

  1. 2026-09-15 v7.1.0 feature

    Breaking: hex_to_rgb now raises an error for hex codes of invalid length and warns on codes with alpha; map traces now need newer browsers (Safari 15, Chrome 56, Firefox 51).

    Draw a marginal heatmap strip in density_heatmap by setting marginal_x or marginal_y to heatmap, sharing the main plot's color scale.

  2. 2026-08-25 v7.0.0 breaking

    Breaking: Removed the deprecated figure factory create_ functions, Orca and Kaleido below 1.0, the engine argument, and the mapbox traces; switch to the map equivalents and update color strings.

    Add quiver traces to draw vector fields as arrows, and a Share Chart modebar button that creates a chart-sharing link through Plotly Cloud.

  3. 2026-07-29 v7.0.0rc0 breaking

    Breaking: Removed deprecated Figure Factory create_* functions, old Kaleido and Orca image export, the engine argument, and all mapbox traces; switch to map traces, newer Kaleido, and check color formats.

    Create quiver charts to visualize vector fields with arrows, and use a new Share Chart modebar button to generate a sharing link via Plotly Cloud.

  4. 2026-07-09 v6.9.0 fix

    Nothing new for users.

  5. 2026-06-03 v6.8.0 feature

    Set a font directly when creating subplots with make_subplots, and sort unified hover label items by value using the new hoversort layout attribute.

  6. 2024-09-12 v5.24.1 maintenance

    Nothing new for users.

  7. 2024-08-29 v5.24.0 feature

    Draw maps with the new px functions scatter_map, line_map, choropleth_map and density_map, which render with maplibre instead of mapbox.

  8. 2024-07-23 v5.23.0 feature

    Add subtitles to plot titles through the new subtitle attribute on layout title, along with new tick label positioning options and shape vertex shifts.

  9. 2024-05-01 v5.22.0 feature

    Set bold weight, italic style, and small-caps variant on fonts in figures, via the updated Plotly.js 2.32.0 bundled with this release.

  10. 2024-04-17 v5.21.0 feature

    Control stacking order of cartesian traces with the new zorder attribute, and enable hover across multiple subplots sharing an axis, via the Plotly.js 2.31.1 update.
