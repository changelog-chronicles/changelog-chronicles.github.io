Changelog Chronicles what's new in Python packages, one sentence per release about

plotly

plotly/plotly.py · PyPI plotly · JSON · edit

  1. 2026-09-15 v7.1.0 breaking

    Breaking: hex_to_rgb now raises an error for invalid-length hex codes, and map traces need newer browsers (Safari 15, Chrome 56, Firefox 51); fix inputs or upgrade.

    Draw a marginal heatmap strip in density_heatmap by setting marginal_x or marginal_y to heatmap.

  2. 2026-08-25 v7.0.0 breaking

    Breaking: Removed deprecated figure factory create_* functions, Orca, old Kaleido, and mapbox traces; switch to px or graph_objects equivalents, map traces, and Kaleido 1.0 or later.

    Draw vector fields as arrows using the new quiver trace type from the updated plotly.js 4.0.0.

  3. 2026-07-29 v7.0.0rc0 breaking

    Breaking: Removed Figure Factory create_* functions, the engine argument, Orca and old Kaleido, and mapbox traces; switch to Kaleido 1.0+ and map traces.

    Add the quiver trace type to visualize vector fields using arrows.

  4. 2026-07-09 v6.9.0 breaking

    Breaking: The modebar button sendDataToCloud was renamed to sendChartToCloud, so update any modebar configuration that references the old name.

  5. 2026-06-03 v6.8.0 feature

    Set a font for the whole figure directly through a new optional font parameter in make_subplots.

  6. 2024-09-12 v5.24.1 maintenance

    Nothing new for users.

  7. 2024-08-29 v5.24.0 feature

    Create maplibre-based maps with the new px functions scatter_map, line_map, choropleth_map, and density_map.

  8. 2024-07-23 v5.23.0 feature

    Add subtitles to plots using the new subtitle attribute on the layout title.

  9. 2024-05-01 v5.22.0 feature

    Use bold weight, italic style and small-caps variant options for fonts in figures.

  10. 2024-04-17 v5.21.0 feature

    Control the stacking order of SVG traces within a cartesian subplot using the new zorder attribute.
