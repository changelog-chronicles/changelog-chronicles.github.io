  1. 2026-10-14 v0.49.0 breaking

    Breaking: Python script and expr tasks now get a different sys.argv (parsed declared args with defaults, then args after --); update code that reads sys.argv.

    Customize the string values boolean args are exposed as using the true_string and false_string options.

  2. 2026-07-05 v0.48.0 feature

    Load environment variables for a task from another task's output, treated like an env file, using the uses_env option.

  3. 2026-07-01 v0.47.1 fix

    Nothing new for users.

  4. 2026-06-27 v0.47.0 breaking

    Breaking: Executor config now rejects unknown keys, so remove any unrecognized keys from executor settings in your pyproject.

    Buffer output from parallel tasks so each task's output appears together, using the new buffer output_mode.

  5. 2026-05-15 v0.46.0 feature

    Use :- and :+ parameter expansion operators everywhere in templating, including inside env files.
