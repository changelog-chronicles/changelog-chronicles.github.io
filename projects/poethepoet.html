poethepoet

nat-n/poethepoet · PyPI poethepoet · JSON

  1. 2026-10-14 v0.49.0 breaking

    Breaking: Python script and expr tasks now get a different sys.argv (parsed declared args with defaults, then args after --); update code that reads sys.argv.

    Customize the string values boolean args are exposed as using the true_string and false_string options.

  2. 2026-07-05 v0.48.0 feature

    Load environment variables from another task's output, treated like an env file, by using the new uses_env task option.

  3. 2026-07-01 v0.47.1 fix

    Nothing new for users.

  4. 2026-06-27 v0.47.0 breaking

    Breaking: Executor config now rejects unknown keys, so configs with typos or unsupported executor options will fail validation; remove or correct those keys.

    Buffer the output of parallel tasks with the new buffer output_mode, so each task's output appears together instead of interleaved.

  5. 2026-05-15 v0.46.0 feature

    Install an experimental agent skill that teaches AI coding agents poe's task API, and use environment variable parameter expansion inside env files.

Briefs and poems are written by Claude from the release notes; the release notes are the source of truth. Data for agents: llms.txt.
