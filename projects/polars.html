polars

pola-rs/polars · PyPI polars · JSON

  1. 2026-10-25 py-2.1.0 breaking

    Breaking: Eager arithmetic mixing string and numeric values is now disallowed and raises an error; convert types explicitly. Python 3.10 support is also dropped, so use 3.11 or newer.

    Write encrypted Parquet files and read encrypted ones, and use recursive SQL CTEs, SQL ASOF joins and masked numpy array conversion.

  2. 2026-10-06 py-2.0.0 breaking

    Breaking: SQL window functions over grouped rows and QUALIFY now behave differently, SQL numeric literals are Decimal, Parquet ENUM reads as String, and cut/qcut are deprecated; review these usages.

    Run SQL GROUPING SETS, ROLLUP and CUBE queries, use the new pipe_with_dtype expression, and scan Lance datasets with the unstable scan_lance.

  3. 2026-09-20 py-2.0.0-rc.2 breaking

    Breaking: Parquet ENUM columns now read as pl.String, cut/qcut are deprecated, POLARS_STREAMING_CHUNK_SIZE is removed, and 0-width frame behavior changed; update code relying on these.

    Group SQL queries with GROUPING SETS, ROLLUP and CUBE, and use the new Map dtype and binning functions.

  4. 2026-09-09 py-1.44.2 maintenance

    Nothing new for users.

  5. 2026-09-02 py-2.0.0-rc.1 breaking

    Breaking: SQL queries now run on the streaming engine by default, which may change behavior or results; check your SQL code and the 2.0 migration guide.

    Write partitioned Iceberg sinks and set Iceberg writer options, and use join reordering plus strip_prefix and strip_suffix on expression names.

  6. 2024-10-01 py-1.9.0 breaking

    Breaking: Python 3.8 is no longer supported, so upgrade to Python 3.9 or newer; struct ne_missing and eq_missing now return true/false values instead of null.

    Read parquet files with allow_missing_columns, a schema argument, and include_file_paths, and use bitwise operations and aggregations on columns.

  7. 2024-09-24 py-1.8.2 fix

    Nothing new for users.

  8. 2024-09-23 py-1.8.1 fix

    Nothing new for users.

  9. 2024-09-23 py-1.8.0 breaking

    Breaking: Comparing Series of unequal length now raises an error, and reading parquet files with extra columns raises unless you select columns; fix such code or add select.

    Do arithmetic between list-dtype Series, and run single inequality joins with join_where.

  10. 2024-09-12 rs-0.43.1 fix

    Nothing new for users.
