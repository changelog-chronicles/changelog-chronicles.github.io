polars

pola-rs/polars · PyPI polars · JSON

  1. 2026-10-25 py-2.1.0 breaking

    Breaking: Python 3.10 is no longer supported, and eager arithmetic mixing strings and numbers now raises an error; upgrade Python and cast columns explicitly.

    Read and write encrypted Parquet files.

  2. 2026-10-06 py-2.0.0 breaking

    Breaking: SQL window/QUALIFY semantics, SQL numeric literals now Decimal, Parquet ENUM now reads as String, and cut/qcut deprecated; review affected queries.

    Run larger-than-memory queries out of core by default, with a new streaming sort and an 80% RAM threshold.

  3. 2026-09-20 py-2.0.0-rc.2 breaking

    Breaking: Parquet ENUM columns now read as String, cut/qcut are deprecated, and the POLARS_STREAMING_CHUNK_SIZE setting is removed; update affected code.

    Group SQL queries with GROUPING SETS, ROLLUP, CUBE and GROUPING() in the SQL frontend.

  4. 2026-09-09 py-1.44.2 maintenance

    Nothing new for users.

  5. 2026-09-02 py-2.0.0-rc.1 breaking

    Breaking: SQL queries now run on the streaming engine by default; if results or behavior differ, explicitly choose the previous engine.

    Write partitioned Iceberg sinks directly from Polars with configurable writer options.

  6. 2024-10-01 py-1.9.0 breaking

    Breaking: Python 3.8 support is dropped, so upgrade to Python 3.9 or newer before installing this release.

    Add bitwise operations and aggregations on expressions and columns.

  7. 2024-09-24 py-1.8.2 fix

    Nothing new for users.

  8. 2024-09-23 py-1.8.1 fix

    Nothing new for users.

  9. 2024-09-23 py-1.8.0 breaking

    Breaking: Comparing Series of unequal length and reading parquet files with extra columns without select() now raise errors; fix input lengths or add select().

    Join dataframes on a single inequality condition using join_where.

  10. 2024-09-12 rs-0.43.1 fix

    Nothing new for users.
