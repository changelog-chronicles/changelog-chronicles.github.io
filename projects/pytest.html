pytest

pytest-dev/pytest · PyPI pytest · JSON · edit

  1. 2026-10-27 9.2.0 breaking

    Breaking: Positional indirect, ids or scope in parametrize now raises TypeError, and pluggy 1.6 or newer is now required; pass them as keywords.

    Set the parametrize_long_str_id_strategy option to control how long string parameter values appear in auto-generated test IDs.

  2. 2026-06-19 9.1.1 fix

    Nothing new for users.

  3. 2026-06-13 9.1.0 breaking

    Breaking: With doctest-modules, inline module, package or session autouse fixtures in test modules may now run twice; move them to conftest.py.

    Add a max-warnings option that fails the test run when the number of warnings exceeds a chosen threshold.

  4. 2026-04-07 9.0.3 breaking

    Breaking: Blocking a conftest.py file with the -p no: option now raises a UsageError, so remove any such option from your configuration.

  5. 2025-12-06 9.0.2 breaking

    Breaking: Terminal progress reporting from 9.0.0 is now off by default except on Windows; enable it again by passing the terminalprogress plugin option.
