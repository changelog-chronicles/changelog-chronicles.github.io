streamlit

streamlit/streamlit · PyPI streamlit · JSON

  1. 2026-11-05 1.67.0 feature

    Breaking: Default theme colors, surfaces, borders and map markers changed, so apps relying on the default look may appear different; check custom styling after upgrading.

    Add st.grid for responsive grid layouts, plus a required parameter on date, time, datetime, text area and selectbox inputs.

  2. 2026-10-21 1.66.1 maintenance

    Nothing new for users.

  3. 2026-10-14 1.66.0 breaking

    Breaking: Python 3.10 support is dropped, so upgrade to Python 3.11 or newer. Apps now render in opaque sandboxed iframes, and httptools is now optional.

    Add on_change="ignore" to many widgets such as color_picker, data_editor, pills and segmented_control, and test forms and more widgets with AppTest.

  4. 2026-10-02 1.65.0 feature

    Add alt text to many elements such as images, charts, tables and dataframes, and show st.dialog as a side drawer using the position parameter.

  5. 2026-09-15 1.64.0 breaking

    Breaking: Inverted st.number_input min/max bounds are now rejected, unsupported on_change modes raise errors, and the mapbox.token config option is removed; fix bounds, modes and config.

    Add native Apache ECharts charts with st.echarts_chart, plus async-aware caching and an on_change ignore mode for number_input, selectbox and select_slider.

  6. 2024-10-13 1.39.1.dev20241012 maintenance poem

    Nothing new for users.

  7. 2024-10-01 1.39.0 feature

    Add icons to st.button, st.download_button, st.form_submit_button, st.link_button and st.popover, and let st.pydeck_chart support selection.

  8. 2024-08-27 1.38.0 breaking

    Breaking: Experimental cached widget replay logic was removed, so code relying on replaying widgets inside cached functions will stop working; move widget calls outside cached functions.

    Pass many more data types, such as Polars, Dask, xarray, Ray, and Pydantic objects, directly to Streamlit's dataframe and data-handling functions.

  9. 2024-08-05 1.37.1 maintenance

    Nothing new for users.

  10. 2024-07-25 1.37.0 breaking

    Breaking: Several deprecated experimental features and old config options were removed, including the showPyplotGlobalUse option; replace removed experimental calls with stable versions and delete removed config settings.

    Add a feedback widget, stacking options for bar and area charts, and stable st.fragment and st.dialog without the experimental prefix.

  11. 2024-06-20 1.36.0 breaking

    Breaking: Legacy caching logic was removed and the experimental_allow_widgets caching parameter is deprecated; update any code that relied on the old caching behavior.

    Build multipage apps with the new navigation and page objects, which let you define pages and their navigation directly in code.
