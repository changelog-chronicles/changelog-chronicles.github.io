streamlit

streamlit/streamlit · PyPI streamlit · JSON · edit

  1. 2026-11-05 1.67.0 breaking

    Breaking: Default theme colors, surfaces, borders and map markers changed, so apps relying on the old look may render differently; set theme values explicitly.

    Add st.grid for building responsive grid layouts in your app.

  2. 2026-10-21 1.66.1 maintenance

    Nothing new for users.

  3. 2026-10-14 1.66.0 breaking

    Breaking: Python 3.10 support is dropped; upgrade to Python 3.11 or newer before installing this release.

    Skip reruns on widget changes by passing on_change="ignore" to widgets such as st.color_picker, st.pills, and st.data_editor.

  4. 2026-10-02 1.65.0 feature

    Render st.dialog as a side drawer by choosing its position.

  5. 2026-09-15 1.64.0 breaking

    Breaking: The mapbox.token config option was removed, so delete it from your config files; st.number_input now rejects inverted min/max bounds.

    Render native Apache ECharts charts in your app with the new st.echarts_chart element.

  6. 2024-10-13 1.39.1.dev20241012 maintenance poem

    Nothing new for users.

  7. 2024-10-01 1.39.0 feature

    Record voice input in your app with the new experimental audio input widget.

  8. 2024-08-27 1.38.0 breaking

    Breaking: Experimental cached widget replay was removed, so remove any use of it from cached functions and move widgets outside them.

    Pass Polars, Dask, Ray, xarray, Pydantic and other dataframe-like data directly to Streamlit's data display commands.

  9. 2024-08-05 1.37.1 maintenance

    Nothing new for users.

  10. 2024-07-25 1.37.0 breaking

    Breaking: Deprecated experimental features and old config options were removed, including deprecation.showPyplotGlobalUse; delete those config entries and switch to the stable APIs.

    Add a feedback widget to collect thumbs or star ratings from users in your app.

  11. 2024-06-20 1.36.0 breaking

    Breaking: Legacy caching logic was removed and experimental_allow_widgets is deprecated; update cached functions that relied on the old behavior.

    Build multipage apps with the new st.navigation and st.Page, which let you define pages and navigation in code.
