  1. 2026-11-26 0.0.112 feature

    Use the input type of an attrs converter method when checking generated constructor arguments and field assignments.

  2. 2026-11-25 0.0.111 fix

    Nothing new for users.

  3. 2026-11-25 0.0.110 feature

    Opt in to uv discovery of your workspace, Python environment, and dependencies through a new preview project-manager setting.

  4. 2026-11-23 0.0.109 breaking

    Breaking: The unknown-rule ignore diagnostic is renamed unknown-rule-in-ignore-comment; the old name remains an alias, so update configuration and ignore comments to the new name.

    Infer enum.auto() values from preceding members in both class-based and functional enums.

  5. 2026-11-22 0.0.108 breaking

    Breaking: The mismatched-type-name rule is replaced by eight rules; update configuration, CLI flags and suppression comments to use the rule for each constructor.

    Recognize TypeVar, ParamSpec, NewType and similar definitions whose names are only known at runtime, warning that the name cannot be verified.

  6. 2026-11-18 0.0.107 feature

    Show progress and handle Ctrl-C during the initial file indexing in the language server preview.

  7. 2026-11-18 0.0.106 breaking

    Breaking: Incompatible TypeIs narrowings now report under two new rules, so update any ignore comments or rule configuration for the old rule.

    Add a project-manager script setting that can be set to uv for script environments.

  8. 2026-11-17 0.0.105 breaking

    Breaking: Some diagnostics moved to new rules, so update any ignore or severity settings for import-not-found, dataclass post-init, or TypeVar constraints.

    Update imports automatically when renaming Python package folders in the language server.

  9. 2026-11-13 0.0.104 fix

    Nothing new for users.

  10. 2026-11-13 0.0.103 feature

    Resolve pytest fixtures registered through pytest_plugins in the language server.

  11. 2026-11-12 0.0.102 breaking

    Breaking: The invalid-return-type rule is split into three rules and several rules are renamed, so update any ty configuration or suppressions that name them.

  12. 2026-11-11 0.0.101 fix

    Nothing new for users.
