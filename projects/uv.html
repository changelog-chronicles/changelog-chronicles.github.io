uv

astral-sh/uv · PyPI uv · JSON

  1. 2026-11-17 0.13.9 feature

    Use PEP 832 .venv redirect files for project environments, and opt into a preview feature that closes unresponsive HTTP/2 connections.

  2. 2026-11-12 0.13.8 feature

    Install CPython 3.16.0a2 as a managed Python version, with updated pip, zlib and Expat bundled in the managed 3.11 through 3.15 builds.

  3. 2026-11-03 0.13.7 feature

    Request a specific schema version from the workspace metadata command in preview, and get aliased vulnerability records reported as one entry in audit output.

  4. 2026-10-27 0.13.6 feature

    Breaking: The preview uv workspace metadata command now nests each module's owners inside an object, so scripts parsing its output need updating.

    Install newer CPython builds (3.11.18, 3.12.16, 3.13.18, 3.14.10, 3.15.2) and detect NVIDIA GPU capabilities when selecting wheel variants in preview.

  5. 2026-10-22 0.13.5 breaking

    Breaking: Invalid custom build cache keys are now rejected instead of silently falling back to defaults, so fix any malformed cache key settings; uv no longer publishes Docker images for Python 3.9 and 3.10.

    Install the latest managed CPython 3.15.1, 3.14.9 and 3.13.17 security releases, which ship with pip 26.2.2 and an updated certificate bundle.
