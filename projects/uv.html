astral-sh/uv · PyPI uv · JSON · edit

  1. 2026-11-17 0.13.9 feature

    Use PEP 832 .venv redirect files for project environments, available as a preview feature.

  2. 2026-11-12 0.13.8 feature

    Install CPython 3.16.0a2 as a managed Python version.

  3. 2026-11-03 0.13.7 feature

    Request a specific schema version from the workspace metadata command using the new output-version option (preview feature).

  4. 2026-10-27 0.13.6 breaking

    Breaking: In preview, uv workspace metadata output now nests each module's owners in an object; update scripts that parse that output.

    Reuse cached or active environments when running PEP 723 scripts that have no dependencies, making them start faster.

  5. 2026-10-22 0.13.5 breaking

    Breaking: Docker images with uv are no longer published for Python 3.9 and 3.10; move to a newer Python version image.

    Install updated managed CPython 3.15.1, 3.14.9 and 3.13.17 builds with security patches and a pip that no longer trusts the affected root.
