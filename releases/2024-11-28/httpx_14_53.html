httpx 0.28.0 breaking

2024-11-28 · Version 0.28.0 · release notes

Breaking: The proxies and app arguments are removed, so switch to the proxy argument and a transport instead; string verify and cert arguments now emit deprecation warnings.

Use socks5h as a valid proxy scheme, and send JSON request bodies in a more compact form.
