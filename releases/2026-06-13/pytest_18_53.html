pytest 9.1.0 breaking

2026-06-13 · None · release notes

Breaking: With doctest-modules, inline module, package or session-scoped autouse fixtures in test modules may now run twice; move them to conftest.py to avoid this.

Register fixtures programmatically with the new register_fixture function, or fail a run when warnings exceed a threshold using the new max-warnings option.
