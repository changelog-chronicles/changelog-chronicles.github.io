dbt v2.0.11 breaking

2026-11-03 · release notes

Breaking: Environment variables were renamed: DBT_AI_PROVIDER is now DBT_ENGINE_AI_PROVIDER, and the info-schema variables now use the DBT_ENGINE_ prefix; update any scripts or CI that set them.

Configure BigQuery query reservations at the model and connection levels, and use the new state-mode flag in place of run-cache-mode.
