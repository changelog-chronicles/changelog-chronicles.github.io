Limits, Renames, and Job Handles

Weekly poem of 2026-11-24 · all weeks

The releases

  1. 2026-11-23 ty 0.0.109 breaking

    Breaking: The unknown-rule ignore diagnostic is renamed unknown-rule-in-ignore-comment; the old name remains an alias, so update configuration and ignore comments to the new name.

    Infer enum.auto() values from preceding members in both class-based and functional enums.

  2. 2026-11-23 lancedb v0.42.0-beta.26 fix

    Nothing new for users.

  3. 2026-11-23 lancedb v0.42.0-beta.25 fix

    Nothing new for users.

  4. 2026-11-22 lancedb v0.42.0-beta.24 fix

    Nothing new for users.

  5. 2026-11-22 ty 0.0.108 breaking

    Breaking: The mismatched-type-name rule is replaced by eight rules; update configuration, CLI flags and suppression comments to use the rule for each constructor.

    Recognize TypeVar, ParamSpec, NewType and similar definitions whose names are only known at runtime, warning that the name cannot be verified.

  6. 2026-11-22 lancedb v0.42.0-beta.23 maintenance

    Nothing new for users.

  7. 2026-11-22 lancedb v0.42.0-beta.22 breaking

    Breaking: GPU settings and total execution limits are now layered, and SQL queries gain timeout controls, so review existing GPU and query-limit configuration.

    Resume a failed Function refresh from its table instead of starting the refresh over.

  8. 2026-11-21 lancedb v0.42.0-beta.21 breaking

    Breaking: Job objects in the Python SDK now expose data only through methods, so replace direct attribute access with the matching method calls.

    Compare table versions with the new table delta API to see which rows changed between them.

  9. 2026-11-18 ty 0.0.107 feature

    Show progress and handle Ctrl-C during the initial file indexing in the language server preview.

  10. 2026-11-18 fastapi 0.165.0 feature

    Configure limits on form parsing, so you can control how much form data your FastAPI app will accept.

  11. 2026-11-18 fastapi 0.164.0 feature

    Set configurable limits on request body size to control how large incoming requests can be.

  12. 2026-11-18 ty 0.0.106 breaking

    Breaking: Incompatible TypeIs narrowings now report under two new rules, so update any ignore comments or rule configuration for the old rule.

    Add a project-manager script setting that can be set to uv for script environments.

  13. 2026-11-18 lancedb v0.42.0-beta.20 breaking

    Breaking: The SDK now returns typed job handles for SQL compaction and data prewarm, so code using the old return values must be updated.

    Run compaction and data prewarm through SQL with typed job handles that you can track.

  14. 2026-11-17 fastapi 0.163.2 maintenance

    Nothing new for users.

  15. 2026-11-17 lancedb v0.42.0-beta.19 breaking

    Breaking: Row failure recovery APIs for functions were added as a breaking change; the notes give no details, so check your function code.

    Expose inspection of the Function worker stack so you can see what function workers are doing.

  16. 2026-11-17 ty 0.0.105 breaking

    Breaking: Some diagnostics moved to new rules, so update any ignore or severity settings for import-not-found, dataclass post-init, or TypeVar constraints.

    Update imports automatically when renaming Python package folders in the language server.

  17. 2026-11-17 lancedb v0.42.0-beta.18 breaking

    Breaking: Function terminal results now expose a descriptor refresh plan and Python Function globals are captured differently; check code relying on the old behavior.

    Capture Arrow and structured Function globals in Python functions so they can be used inside those functions.
